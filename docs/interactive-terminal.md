# Интерактивный терминал компьютера

В карточке компьютера открывается настоящий интерактивный Bash с Linux PTY.
Поддерживаются Tab, история, Ctrl+C/Ctrl+D, `cd`, ANSI-цвета, полноэкранные
программы и изменение размера. На сайте используется xterm.js с одной областью
прокрутки всего сеанса. Заголовок панели — «Консоль от имени root». Кнопок очистки и завершения нет:
`clear`/Ctrl+L очищают экран, `exit`/Ctrl+D закрывают Bash.

Сеанс создаётся только после «Подключиться». Текущий каталог сохраняется на ПК
отдельно для каждого оператора и стенда в `/var/lib/digital-examen/terminal/`.
После навигации можно подключиться к существующему сеансу; после его завершения,
перезагрузки или обновления новый Bash начинает с сохранённого каталога.
Сохранённые данные доступны только root. Команды запускаются от того же root,
от которого до изменения работала консоль; дополнительных прав на сайте нет.

Авторизация перепроверяется при каждом запросе: нужны права просмотра и управления
компьютерами, сохраняется защита системного компьютера. Сеансы привязаны к
компьютеру и оператору. Секрет отдельного ПК не позволяет открыть терминал или
получить сеанс другого ПК. Браузер не получает секретов агента или приёмника.

Транспорт использует уже существующие HTTPS-точки и секреты, без новых внешних
портов. В активном терминале ввод доставляется ожидающему запросу агента, вывод
передаётся по мере появления. Соединения агента переиспользуются; при отсутствии
открытого терминала дополнительного опроса нет. Ввод подтверждается порядковыми
номерами; повтор передачи вывода не дублирует текст.

После 90 секунд без запросов браузера сеанс закрывается, каталог сохраняется.
Хранится не более 1 МиБ вывода на сеанс; при переполнении удаляется начало,
пользователю показывается уведомление. Ограничены очереди ввода, количество
сеансов и размер терминала. При заморозке ввод запрещён сервером, PTY закрываются
агентом, терминальный вывод больше не передаётся. После разморозки оператор может
подключиться снова в сохранённый каталог.

Проверки: реальный PTY под Linux-пользователем test (дополнение файлов Tab,
cd/восстановление каталога, Ctrl+C, resize, пользователь процесса), HTTP-сеанс
через настоящий приёмник, разделение операторов/ПК и запрет ввода при заморозке.

## Нагрузка открытых сеансов

Нажатие «Подключиться» создаёт или присоединяет один сеанс для пары оператор–ПК;
просмотр карточки сам по себе Bash не создаёт. xterm загружается отдельным чанком
только для карточки с доступной консолью и исключён из обфускации production.

В покое браузер и агент держат по одному ожидающему запросу. Ожидание — до 45 с;
при вводе или выводе запрос просыпается сразу, без ожидания конца периода.
Частота пустых обменов снижена с 18 до 45 секунд: это на 60% меньше обменов.
Два пустых JSON-ответа за цикл суммарно занимают около 100 байт, то есть около
0,13 КиБ/мин без учёта HTTP/TLS-заголовков. Общий сетевой расход зависит от
размеров авторизации, TLS и повторных подключений; тела команд и вывода в покое
не передаются. Снимки экранов — отдельный трафик страницы и в эту оценку не входят.

Сеанс не перезапускается на каждую команду. Пока окно подключено, он может
оставаться открытым без ограничения по времени. После потери окна/связи срок
хранения сеанса — 90 с; рабочий каталог сохранится и после закрытия. При freeze
PTY и его сетевые соединения закрываются сразу. Молчание Bash не запускает
сетевой опрос вывода. Поток большой команды ограничен примерно 160 КиБ/с на сеанс
естественным обратным давлением PTY: данные не отбрасываются на агенте.
