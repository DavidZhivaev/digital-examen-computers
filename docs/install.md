# Раскатка компьютера одной командой

На чистой машине под МОС 12:

```
git clone https://github.com/DavidZhivaev/digital-examen-computers.git
cd digital-examen-computers
sudo sh run.sh
```

Всё остальное скрипт делает сам. Заранее ничего настраивать и доставлять не
нужно.

## Что делает run.sh по шагам

1. **Проверяет и доставляет всё нужное** (`bin/de-deps`). Если чего-то нет -
   ставит пакетным менеджером, какой найдёт: `apt-get`, `dnf`, `yum`,
   `zypper` или `pacman`. Проверяется каждая вещь, которой мы пользуемся:

   | Что | Зачем |
   |---|---|
   | `git` | обновления из репозитория |
   | `python3` (3.8 и новее) | вся логика написана на нём |
   | `curl` | проверки связи |
   | `rsync` | наполнение домашней папки из `/etc/skel` |
   | `ip`, `nft` | сетевое пространство имён и замок на выход |
   | `setpriv` | запуск сеанса от имени ученика внутри namespace |
   | `ffmpeg` | съёмка экрана |
   | ImageMagick (`magick` или `convert`) | нарезка кадра и палитра |
   | `systemd-nspawn` | песочница `de-box` |
   | `cryptsetup` | зашифрованный том с секретами и записями |
   | `tpm2-tools`, `systemd-cryptenroll` | ключ тома в микросхеме TPM |
   | `sudo`, `visudo` | правила для учеников и владельцев ключа |
   | bcrypt | проверка пароля при входе **без интернета** |
   | `hashlib.scrypt` | то же, вторая ступень |

   bcrypt берётся сначала из системного `crypt` (на МОС 12 он умеет `$2b` и
   считает на C), потом из модуля `python3-bcrypt`, и только потом через
   `pip`. Если не вышло ничем - скрипт прямо говорит, что вход без интернета
   работать не будет.

2. **Переносит репозиторий** в `/opt/digital-examen-computers` и дальше
   работает оттуда. Потом компьютер сам проверяет обновления раз в 15 минут.

3. **Запускает `setup.sh`**: скрипты, модули, конфиг, группы, запрет ssh и
   текстовой консоли ученикам, экран входа, хуки PAM, службы, правила sudo.

4. **Включает шифрование** (`de-encrypt enable`): создаёт том LUKS2 и
   переносит в него секреты, выгрузку учёток, очередь кадров и состояние
   пользователей. Отключается `DE_SECURE_DISK=0` в конфиге.

5. **Просит ключ администратора** и ставит компьютер на учёт (`de-init`):
   спрашивает корпус, аудиторию, номер, получает **свои** секреты, забирает
   выгрузку учёток для входа без интернета.

6. **Перезагружается.** После перезагрузки на экране входа ученик вводит
   логин и пароль с сайта.

## Повторный запуск и обновления

`sudo sh run.sh` можно запускать сколько угодно: конфиг не перезаписывается,
хук PAM не дублируется, том не создаётся второй раз, список защищённых
пользователей не меняется. Обновление из репозитория идёт само
(`de-update.timer` → `setup.sh --update`), и в этом режиме компьютер не
переставляется на учёт и не перезагружается.

## Если что-то пошло не так

```
sh bin/de-deps                 # чего не хватает
de-encrypt status              # состояние зашифрованного тома
de-vault show                  # выгрузка учёток
de-init                        # переставить компьютер на учёт
tail -f /var/log/digital-examen-computers.log
```

Откатить правку экрана входа:

```
cp /etc/pam.d/sddm.before-digital-examen /etc/pam.d/sddm
```

## Python

На МОС 12 системный `python3` - **3.8**, и всё написано под него: никаких
`match`, `str.removeprefix`, обобщений встроенных типов в аннотациях и
прочего из 3.9+. Проверяется механически - разбором каждого файла с
`feature_version=(3, 8)` и компиляцией живым `python3.8`.
