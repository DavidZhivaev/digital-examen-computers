# Ключ и установка компьютера

## Откуда берётся ключ

Кнопка «Скачать ключ» в подсистеме «Компьютеры» видна администраторам
предмета «Информатика» и администраторам школы и выше. Она выдаёт файл
`de-key.txt` — его кладут в корень флешки.

Сайт хранит только отпечаток ключа и хеш его секрета. Сам секрет существует
ровно в одном экземпляре — на флешке.

## Установка

```
sudo sh setup.sh
```

В конце установки скрипт просит вставить флешку с ключом и ждёт её. Дальше:

1. ключ проверяется на сайте — не отозван ли, цел ли секрет;
2. проверяется, есть ли **сейчас** у владельца ключа право ставить
   компьютеры. Право проверяется каждый раз, а не в момент выдачи: сняли
   человека с администраторов информатики — его ключ перестал работать;
3. спрашиваются номер корпуса, аудитории и компьютера;
4. компьютер регистрируется на сайте и получает имя вида `2k-419-16`.

Компьютерный класс заводится сам при регистрации первого компьютера в нём.
Отдельно создавать кабинет не нужно.

## Та же флешка как ключ от sudo

Пока флешка с ключом вставлена, её владелец — и только он — получает `sudo`
на этом компьютере. Вынули флешку — право забирается.

Делает это `bin/de-keywatch`: раз в пять секунд смотрит, есть ли на
подключённом сменном носителе файл с известным именем, и если есть —
проверяет его на сайте. Совпал ли владелец ключа с тем, кто сейчас вошёл,
решает тоже сайт.

Читается только файл с заранее известным именем в корне носителя. Ничего не
ищется рекурсивно, ничего больше не открывается и не запускается.
